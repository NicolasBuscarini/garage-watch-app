# Arquitetura do protótipo T00a

O serviço é um monólito modular Python executado em container. `VideoSource` é uma porta de entrada: `OpenCVCameraSource` usa webcam de desenvolvimento e `SyntheticSource` é a implementação contratual de testes. Uma fonte RTSP pode ser introduzida depois de T00/T01 sem importar APIs OpenCV para o domínio.

`CaptureRuntime` escreve segmentos AVI/MJPEG de duração limitada no buffer circular local. Cada segmento tem manifesto JSON atômico com `camera_id`, `stream_epoch`, sequência, timestamps UTC, bytes e SHA-256. Falhas da fonte geram arquivos de lacuna e cada reconexão cria novo `stream_epoch`; gaps entre reinicializações também são registrados. Clipes são pedidos manualmente por HTTP; o job é persistido antes da espera da janela pós-evento, a fila tem limite `MAX_PENDING_CLIPS`, e segmentos que intersectam jobs pendentes ficam fixados. O arquivo local valida cota e checksum, limita o temporário de cada clipe a `MAX_CLIP_BYTES`, reconcilia jobs e manifestos no startup e remove arquivos temporários/orfãos.

O estado usa somente disco local persistente; não há banco, NAS, inferência ou aplicativo neste incremento. `/health/live`, `/health/ready`, `/api/v1/status`, `/api/v1/clips` e `/metrics` são endpoints locais de desenvolvimento. O Compose publica a API somente em loopback do host. Não é um gateway de mídia autenticado para uso em LAN/produção.

Limites: jobs de clipe são persistentes em JSON e processados por um worker local; uma única instância do serviço é suportada. AVI/MJPEG é formato operacional de protótipo, não decisão de formato arquivístico. O clipe informa `pre_buffer_complete`, `post_buffer_complete` e `gap_count`; limites do vídeo são alinhados aos segmentos e não garantem corte exato no milissegundo do gatilho. Antes de montar, verifica-se o tamanho agregado dos segmentos e a reserva de espaço; após codificar, um arquivo maior que `MAX_CLIP_BYTES` é removido e o job falha. O tamanho temporário pode exceder brevemente essa marca durante a codificação, pois OpenCV libera buffers ao fechar o writer; a reserva livre é exigida para reduzir risco de esgotar o host. A escrita de segmento pode ultrapassar temporariamente a cota em até um segmento antes de ser descartada com lacuna explícita. Não apagar arquivos pendentes para obter espaço. A API de desenvolvimento não tem autenticação; o Compose usa bridge padrão para viabilizar o encaminhamento da porta, mas publica a API somente no loopback do host.
